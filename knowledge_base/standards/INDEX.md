## 第二部分：干线绿波协调控制核心国家标准与规范
### 2.1 《城市道路交通组织设计规范》（GB/T 36670-2018）
- **适用条件**：路段上交通特征相似、关联性强、间距不超过500m的交叉口宜实施交通信号协调控制。
- **干扰控制**：为保证交通信号协调控制效果，可通过设置隔离护栏、减少出入口或限制出入口的进出等方式减少横向干扰，维持车流运行稳定。
- **信号控制机**：交叉口交通信号控制机及交通信号控制系统应满足协调控制要求。
- **协调方案设计内容**：主要包括：确定协调方向、确定关键交叉口、划定协调子区、划分协调时段、确定公共周期、测定相位差。

### 2.2 《道路交通信号控制系统通用技术要求》（GB/T 39900-2021）
- **控制方式**：系统应支持定时控制（含干线定时协调控制）、感应控制（含干线感应协调控制）、自适应控制及人工干预。
- **配时参数**：支持公共周期、相位差、绿信比等协调控制参数的配置，宜支持通过时距图的方式配置。
- **绿信比分配原则**：在信号协调控制中，各个交叉口的绿信比影响绿波带宽度。通常根据各个交叉口各向流量比来确定。一般原则是为干道上的重交通流（如直行）所在信号相位分配较多绿灯时间，为其他交通流方向所在信号相位分配较少绿灯时间，以保证绿波带宽度。

## 第三部分：交通信号控制基础理论（计算基石）
### 3.1 基本信号配时参数
1. **周期时长（Cycle Length, C）**：一个相位的信号灯色变化一个循环所用的时间。C = G + A + R（绿灯+黄灯+红灯）。交通流量越大，周期越长；通常控制在60-150秒，不超过180秒。
2. **有效绿灯时间（Effective Green Time, ge）**：实际上被机动车有效利用了的绿灯时间。由于启动损失和停车损失，有效绿灯时间 = 绿灯时间 + 黄灯时间 - 损失时间。
3. **绿信比（Split, λ）**：有效绿灯时间与周期的比值。λ = ge / C。反映了该相位在周期内所占的时间资源比例。
4. **绿灯间隔时间（Intergreen Time, I）**：一个相位的绿灯结束到下一个相位的绿灯开始之间的时间。I = 黄灯时间 + 全红时间。全红时间用于清空交叉口冲突区。
5. **饱和流率（Saturation Flow Rate, S）**：在一次连续的绿灯信号时间内，进口车道上一列连续车队能通过停车线的最大流量（pcu/h）。
6. **流量比（Flow Ratio, y）**：到达车流量(q)与饱和流量(S)的比值，y = q / S。交叉口总流量比 Y = Σy。
7. **通行能力（Capacity, Cap）**：信号交叉口某进口车道的通行能力 Cap = λ * S = (ge / C) * S。
8. **饱和度（Degree of Saturation, x）**：进口车道的车流量(q)与通行能力(Cap)的比值，x = q / (λ * S)。x<0.6为A/B级畅通，0.75-0.9为D级拥挤，>1.0为F级阻塞。

### 3.2 Webster最佳周期公式
在单点定时控制中，寻找使车辆总延误最小的最佳周期：
\[
C_0 = \frac{1.5L + 5}{1 - Y}
\]
其中：
- L：每个周期的总损失时间。L = Σ(绿灯间隔时间 + 启动损失时间)。通常 L ≈ 4s * 相位数。
- Y：交叉口各相位关键车流流量比之和。
*注意：计算出的C0若小于最小周期（如60s）或大于最大周期（如150s），需进行边界截断。*

### 3.3 关键车流判定
关键车流是指那些能够对整个交叉口的通行能力和信号配时设计起决定作用的车流。关键车流也就是交通状况相对较差的车流。
判定方法：
- 将各流向车流分配到对应的相位阶段中。
- 找出每个阶段中流量比(y)最大的车流，作为该阶段的代表性车流。
- 绘制“信号相位与车流对应关系图”，寻找关键路径，满足通行能力要求的最长路径对应的车流即为关键车流。

## 第四部分：干线绿波协调控制核心理论
### 4.1 干线协调控制的四大基本参数
1. **公共周期时长**：在信号协调控制中，为了保持住各个交叉口之间的最佳相位差，各个交叉口的周期时长必须相等。计算方法是：先计算各个交叉口单点定时控制所需的最佳周期，然后从中选择最大的周期时长作为线控中的公共周期时长。对应最大周期时长的交叉口叫做“关键交叉口”。特殊情况下，部分流量极小的路口可采用“双周期”（即公共周期的一半）。
2. **相位差**：相邻路口间建立协调关系的关键参数，直接决定线控系统运行的有效性。
   - **绝对相位差**：各信号的绿灯或红灯的起点相对于某一个标准信号绿灯或红灯起点的时间之差。
   - **相对相位差**：相邻两信号的绿灯或红灯的起点之间的时间之差。等于两个绝对相位差之差。
3. **绿信比**：分配各相位时间比例，影响绿波带宽度。
4. **通过带（绿波带）**：在时间-距离图上，画两条平行的车辆行驶轨迹线，尽可能靠近各交叉口绿灯时间的起点和终点。两条轨迹线之间的空间称为通过带。其纵坐标之差即为通过带宽度，表示可供车辆使用以通过交叉口的时间。

### 4.2 协调控制的分类
1. **定时式线控系统**：事先按干道上交叉口的分布和交通流情况制定不同时段的协调控制方案，存入系统。
2. **感应式线控系统**：根据车辆检测器测出的交通流信息，实时调用不同的感应信号控制方案。
3. **单向干道协调控制**：以单方向交通流为优化对象的线控方式，常用于单向交通、变向交通或两个方向交通量相差悬殊的道路。
   - 理想相位差公式：\(O = mod(s / v, C)\)  （s为间距，v为车速，C为周期，mod为取余）。
4. **双向干道协调控制**（双向绿波）：
   - **同步式协调**：相邻交叉口间距符合 \(S = n * v * C\)（n为正整数）。全部信号在同一时刻对干道显示相同灯色。
   - **交互式协调**：相邻交叉口间距符合 \(S = m * v * C / 2\)（m为奇数）。相邻信号在同一时刻显示相反灯色。
   - **续进式协调**：根据道路上的要求车速与交叉口间距，确定合适的相位差，使上游绿灯驶出的车辆，正好在下游绿灯期间到达。

## 第五部分：绿波方案设计的核心算法（数解法与图解法）
### 5.1 数解法（经典双向绿波相位差计算方法）
数解法的核心思想：寻找使得系统中各实际信号位置距理想信号位置的最大挪移量最小来获得最优相位差控制方案。

**步骤1：计算理想信号间距a**
- 先计算 \(vC / 2\) （v为带速，C为周期）。这代表相距该距离的两个路口，时差相当于交互式协调（错半个周期）。
- 以 \(vC / 2\) 的数值在实用允许范围内变动（通常以10m为单位），逐一计算，寻求协调效果最好的各理想信号位置。

**步骤2：计算挪移量**
- 以第一个路口为起始点，算出下游各实际信号位置同各理想信号位置的错移距离。
- 错移距离 = (上一个挪移量 + 实际间距) - 理想信号间距a。若大于a，则减去a（即跨入下一个理想信号周期）。

**步骤3：计算b值并确定最佳理想位置**
- 将实际信号位置与理想信号位置的挪移量按顺序排列（从小到大）。
- 计算各相邻挪移量之差，将此差值最大者记为 \(b\)。
- 寻找合适的 \(a\) 值，使得 \(a-b\) 的差值最小。此时对应的理想信号位置即为最优。
- 理想信号位置距第一个实际路口的距离为 \((a - b) / 2\)。

**步骤4：作连续行驶通过带（带宽计算）**
- 将理想信号位置编号依次列在最靠近的实际信号位置下面。
- 将各信号在理想信号位置的左右位置填入表内。
- 计算各交叉口信号配时所得的主干道绿信比（λ），列入表内。
- 计算因位置不一致造成的绿时损失（%）= 挪移量 / 理想信号间距a。
- 有效绿信比 = 绿信比(λ) - 绿时损失。
- 连续通过带带宽 = 左右两端有效绿信比最小值的平均值。

**步骤5：计算相位差**
- 奇数理想信号点对应的实际交叉口（同步式协调）相位差 = \(100\% - 0.5 \times \lambda\)。
- 偶数理想信号点对应的实际交叉口（交互式协调）相位差 = \(50\% - 0.5 \times \lambda\)。
- 根据相位差绘制时距图，利用数学解析法求出正反向绿波宽度（截距公式计算）。

### 5.2 图解法
通过几何作图利用时间-距离图初步建立交互式或同步式协调系统。
**步骤**：
1. 从基准路口引一条斜线，代表通过带速度推进线（斜率等于车辆行驶车速的倒数）。
2. 斜线与下游路口的交点，接近从基准路口绿灯起点引水平线与该路口的交点，该交点可作为下游路口绿灯起点。
3. 连接基准路口与下游路口的绿灯起点，依次画斜线。
4. 绘出各交叉口的红灯粗线段，配成交互式与同步式组合的双向线控系统。
5. 在图上做出最后的通过带，算出带速和带宽。如果带速过高，需相应加长周期时长，调整绿信比。

## 第六部分：绿波协调控制适用条件与效益提升措施
### 6.1 适用条件
1. **车流到达特性**：交叉口间距不宜过大（通常不超过800米），保证车辆能够形成车队，脉冲式到达。若交叉口间有大量交通流汇入，会破坏车队连续性。
2. **街道行车方式**：单向交通有利于线控系统实施并达到运行效果，应优先考虑。
3. **信号的分相**：相位结构简单的交叉口选用线控效果理想。复杂的多相位会严重削减绿波带宽。
4. **交通量波动**：高峰、平峰期间交通流量大，适合绿波。夜间低峰期流量太小，协调效果差，宜采用黄闪或感应控制。

### 6.2 效益提升辅助措施
1. **前置信号**：在主要交叉口前几十米设置交通信号灯，使车流集中，放行后到达交叉口时正好绿灯。
2. **可变车速指示标志**：设置速度标志（如30、45、60），指示驾驶员以建议车速行驶，正好赶上绿波。
3. **两者合并使用**：采用前置信号与速度指示标志并用的线控系统，可使交叉口不停车通过的比例从55%提高到70%-77%。

## 第七部分：实际工程案例数据复盘（用于对标对表）
**案例：天河北路（东段）交通信号协调控制**
- **现状痛点**：全长1.8公里，12个红绿灯。车主来回停车总次数平均4次，每隔1.5个红绿灯就要停车。高峰期排队等两个灯位。
- **基础数据**：西起体育东路，东至五山路。4个核心交叉口：体育东、天寿路、龙口西、龙口东。
- **间距**：龙口东—龙口西约340m；龙口西—天寿路约440m；天寿路—体育东路约450m。
- **设计速度**：36km/h（即10m/s）。限速40km/h。
- **数解法计算**：
  - 公共周期：假设通过计算单点最优周期，最大值为100s。
  - 理想信号间距a = vC/2 = 10 * 100 / 2 = 500m（但考虑到间距在340-450m之间，取有效数字进行a列试算）。
  - 通过试算，当a=410m时，最大偏移绿信比最小。据此确定各路口相位差（如体育东30%，天寿82.5%，龙口西20%，龙口东75.5%）。
- **效果评估**：
  - 带宽达到32.6s（约周期的1/3）。
  - 平均停车次数由0.45降至0.29。
  - 平均排队长度由18米降至15米。
  - 行程时间由232秒降至147秒。
